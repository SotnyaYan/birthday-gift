# Birthday Gift 🎁

Интерактивное приложение-сюрприз для дня рождения с ребусами и уведомлениями в Telegram.

## 🌟 Функционал

- 🎯 **6 подарков** с персональными описаниями
- 🧩 **Ребусы** перед каждым подарком (можно пропустить)
- ⏳ **Таймер ожидания** между открытием подарков
- 🔔 **Уведомления в Telegram** при открытии каждого подарка
- 📊 **Индикатор прогресса** с точками
- 🎨 **Эстетичный дизайн** в морской голубой теме

## 🚀 Как запустить локально

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

## 🔧 Настройка Telegram уведомлений

1. Создай бота в **@BotFather** (команда `/newbot`)
2. Получи **Bot Token**
3. Получи **Chat ID** через @myidbot
4. Настрой в приложении при первом запуске
