## Детали реализации

### Компоненты:
```
Welcome.jsx      - Экран приветствия
GiftScreen.jsx   - Экран с подарком (открыт/не открыт)
WaitingScreen.jsx - Таймер ожидания
SuccessScreen.jsx - Финальный экран
ProgressIndicator.jsx - Индикатор прогресса (номер + точки)
ResetButton.jsx  - Кнопка сброса
```

### Состояния приложения:
1. **Не начал** → Welcome
2. **Начал, но не открывал** → GiftScreen (с кнопкой "Открыть")
3. **Открыл, ждет** → WaitingScreen (таймер)
4. **Все открыто** → SuccessScreen (финал)

## Время ожидания

Сейчас настроено на **10 секунд** для тестов.  
Можно изменить в `src/utils/timer.js`:

```javascript
// Для тестов:
export const HOUR = 10 * 1000;

// Для реального использования (1 час):
export const HOUR = 60 * 60 * 1000;

// Для 3 часов:
export const HOUR = 3 * 60 * 60 * 1000;
```
